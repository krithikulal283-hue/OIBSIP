# Advanced BMI Calculator

A Python-based Advanced BMI Calculator desktop application developed using Tkinter, SQLite and Matplotlib.

## Features

- GUI-based BMI calculator
- User name management
- Weight and height input
- BMI calculation
- BMI categories
- Colour-coded BMI results
- Input validation
- Multiple-user support
- SQLite database
- BMI history
- BMI trend graph
- Error handling

## Technologies Used

- Python
- Tkinter
- SQLite
- Matplotlib

## BMI Formula

BMI = Weight / (Height × Height)

## BMI Categories

| BMI | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 - 24.9 | Normal |
| 25 - 29.9 | Overweight |
| 30 or above | Obese |
