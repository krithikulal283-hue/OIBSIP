# Advanced Random Password Generator

A Python-based desktop application that generates secure random passwords with customizable options.

## Features

- Generate random passwords
- Choose password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Password strength indicator
- Copy password to clipboard
- Session password history
- Clear password history
- Input validation
- User-friendly GUI

## Technologies Used

- Python
- Tkinter
- Secrets module
