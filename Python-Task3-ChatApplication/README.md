# Advanced Chat Application

A real-time multi-user chat application built with Python.

## Features

- User registration and login
- SQLite database
- Password hashing
- Real-time messaging
- Socket programming
- Multi-user support
- Multiple chat rooms
- Message history
- Timestamped messages
- Emoji shortcode support
- Graceful disconnection
- Tkinter graphical user interface

## Technologies Used

- Python
- Tkinter
- Socket
- Threading
- SQLite
- hashlib
